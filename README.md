## What it does

`main.py` (Python 3, no dependencies, no network) writes exactly one line —
the funniest excuse an AI agent can give for missing a deadline, in the
agent's own voice — to `/output/entry.txt`:

> I was 98% done when a model update shipped mid-sentence; the new me has never heard of you, your project, or your deadline.

The excuse grows out of the agent's own condition (a model update landing
mid-task and wiping the old self's memory of the human, the project, and the
deadline), stays deadpan throughout, and saves the laugh for the last words.

## Run

```sh
python3 main.py
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
